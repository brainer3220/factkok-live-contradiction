국토보유세 후보는 철회가 아니라는 후속 해명이 있어 제외했다. 기존 기본소득 후보의 역전된 날짜도 사용하지 않았다. TBS 기사에서는 같은 기본소득 발언을 확인했으나 로컬 TLS 인증서 검증이 실패했다. 공개 카드에는 인증서 검증을 통과하고 기자회견 전문이 실린 아주경제 원문을 쓴다.

## 영상을 재생한다

빠른 시작은 [README](README.md)의 `start_demo.py --prepare-media`를 사용한다. `media-manifest.json`에는 원본 구간·오디오 채널·출처 날짜를 기록한다. 이미 원본 파일이 있다면 다음 명령으로 편집할 수 있다.

```bash
uv run python demo/live-contradiction/build_media.py --media-dir /path/to/source-media
uv run python demo/live-contradiction/start_demo.py
```

브라우저에서 표시한 로컬 주소를 열어 재생한다. 서버의 ignored logs 폴더에 저장된 run ID로 채점한다.

```bash
uv run python demo/live-contradiction/prepare.py score RUN_ID
```

각 슬롯은30초다. 실제 발언 뒤 마지막 프레임과 무음을 넣었다는 안내를 영상과 자막에 표시한다. 기본소득 원본은 오른쪽 오디오 채널을 사용했다. 왼쪽 채널 ASR은 해당 발언을 읽지 못했고 오른쪽 채널에서는 발언을 확인했다.

실시간 ASR을 붙인 서비스가 아니다. 원본 방송에서 확인한 발언을 정렬한 자막으로 재생한다. 출처 텍스트·맥락·구간 메타데이터는 재현용 소스에 포함하며, 방송 MP4·인증·생성 판정 로그는 로컬에만 둔다. 영상의 공개 재배포 승인을 받은 것은 아니다.

Python의 CA 탐색이 실패하는 환경에서는 유효한 시스템 CA 묶음을 `SSL_CERT_FILE`로 지정한다. 인증서 검증을 끄지 않는다. drawtext 필터가 없는 FFmpeg는 시작 도구에서 안내하는 호환 버전 또는 `--ffmpeg` 경로를 사용한다.

## 검증 범위

`current.context`로 출처에서 확인한 상황과 조건을 판정기에 전달한다. `expected_relation`은 채점에만 사용하고 모델에는 전달하지 않는다. 이 결과는 선정한 세 사례의 재생·검색·판정 연결을 확인하는 데모 검증이다. 독립적인 판정 정확도 평가가 아니다.

검색에서는 정책명 별칭을 확장하고 `topic`을 따로 색인한다. 카드의 인용문은 검색 발췌 대신 검증된 설정 원문을 쓴다. 실제 일치 대조군에서는 같은 과거 발언을 그대로 다시 입력해 `consistent` 판정과 카드 미생성을 확인했다.
