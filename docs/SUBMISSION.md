# 제출 초안

## 이름

팩트콕 · 발언을 원문으로 비교하기

## 짧은 설명

정치 영상을 보다가 “전에는 어떻게 말했지?” 궁금할 때, 인물을 고르고 재생하면 같은 사람의 과거 발언을 날짜와 원문 링크로 바로 비교합니다. gbrain이 발언 기록을 검색하고 Codex의 OpenAI 모델이 두 발언의 관계를 자동 예비 판정합니다. 지금 발언과 과거 인용문을 나란히 읽고 출처를 직접 확인할 수 있습니다.

## 데모에서 볼 수 있는 것

- MagicPath 포트레이트 메인을 실제 인물 선택 화면으로 이식했습니다. 상세는 영상·현재 발언과 과거 기록을 두 영역으로 배치했습니다.
- 이재명 3개 주제와 한동훈 1개 주제에서 실제 gbrain 검색과 `gpt-6-luna` 호출을 실행합니다. 다른 6명은 자료 연결 전으로 표시합니다.
- 검색·판정·실패·재시도 상태를 실제 HTTP/SSE 이벤트에 연결했습니다. 인물을 바꾸면 별도 run으로 시작하고 중복 제출과 이전 결과 유입을 막습니다.
- 카드의 인용문·날짜·매체·URL은 검색에서 선택된 저장 기록을 사용합니다. 모델이 원문을 만들어 넣지 않습니다.

## 90초 화면 녹화

별도 로컬 산출물 `factkok-demo-90s-final.mp4`는 실행 중인 브라우저 탭을 약2fps로 캡처한 무음 화면 녹화입니다. 약90초의 실제 경과 순서를 사용하며 재생 영상, 실제 provider 대기, 한동훈 결과, 인물 목록 복귀, 이재명 재생과 결과를 보여 줍니다. 화면을 사전 판정으로 바꿔 넣지 않았습니다. 앱의 원본 데모 영상에는 음성이 있고 화면 녹화에는 오디오 트랙이 없습니다.

## 구현 범위

녹화 영상과 원문에 정렬한 자막으로 재현하는 로컬 데모입니다. 실시간 ASR·운영 배포를 구현했다고 주장하지 않습니다. 선정한 사례의 검색·판정·출처 연결을 검증했으며 독립적인 모델 정확도 평가는 아닙니다. 조건·시점·상황에 따른 입장 변화는 거짓말과 구분하고 원문 확인을 안내합니다.

행사 제출 폼·공식 규정·영상 업로드 위치는 확인되지 않았습니다. 이 문서는 제출에 사용할 초안이며 실제 제출이나 영상 공개 업로드를 수행한 기록이 아닙니다.
